게임 DB 검색

검색할 때마다 서버 DB를 조회한다. 결과 카드를 누르면 원본 필드와 출처가 열린다.

검색어를 입력하면 Supabase DB에서 바로 가져온다.

스킬 → 장비 조합

스킬 설명·내부명과 실제 장비 설명을 연결해 후보와 근거를 보여준다.

공식 새소식

GNJOY 공지·업데이트·이벤트 수집 테이블에서 최신 자료를 불러온다.

공식 인기 거래자료

GNJOY가 공개한 최근 120일 인기 거래 순위. 보호된 전체 노점 검색은 우회하지 않는다.

기능 현황

서버의 실제 상태표를 불러와 표시한다.

Frontend: GitHub Pages · Database/Auth/API: Supabase · 각 자료는 출처와 관측시각을 보존한다.
